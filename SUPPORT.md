# Support

Start with the [documentation site](https://sayanmohsin.github.io/arqen/),
[FAQ](docs/faq.md), and [feature status](docs/feature-status.md).

For a reproducible bug, open a [bug report](https://github.com/sayanmohsin/arqen/issues/new?template=bug_report.yml)
with the Arqen version, Rust version, operating system, storage mode, and a
minimal reproduction. Do not post credentials, tokens, private customer data,
or an undisclosed security vulnerability in a public issue. Follow
[`SECURITY.md`](SECURITY.md) for security reports.
