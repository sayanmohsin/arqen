# Changelog

Release history for the published `arqen` crate is maintained in
[`crates/arqen/CHANGELOG.md`](crates/arqen/CHANGELOG.md).

## Current release

The current published release is **0.14.0**. It adds the latest Arqen Thingd
compatibility boundary, keeps native Thingd support behind the explicit
`thingd-native` feature, and includes the durable Thingd-backed scheduler.

## Unreleased

Documentation and compatibility notes may be updated on `main` without
creating a new crate release. Release version ownership remains with Release
Please and the crate changelog.
