# Governance

Arqen is maintained as an open-source project by its repository maintainers.
Maintainers are responsible for releases, security response, public API
stability, and the direction of the framework.

Changes to public APIs, storage contracts, release automation, or security
behavior should include a clear rationale, migration notes, tests, and matching
documentation. The project is early-stage, so compatibility promises are
documented in the feature-status page and changelog rather than implied by the
version number.
