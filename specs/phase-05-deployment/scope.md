# Scope\n\n## Intent\n\nMake Arqen applications straightforward to package, operate, and deploy.\n\n## Included behavior\n\nDockerfile, .dockerignore, Compose, environment examples, production logs, readiness, worker deployment, graceful shutdown, generic deployment docs, `arqen doctor`.\n\n## Excluded behavior\n\nCloud-specific adapter implementation, managed Kubernetes operators, billing, and application-specific infrastructure.\n\n## Change boundary\n\nWork only in the Arqen repository and the paths required by this phase. Do not modify sibling repositories unless an explicit compatibility issue is documented and approved.\n
