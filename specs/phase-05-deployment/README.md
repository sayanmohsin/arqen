# Phase 05: Deployment\n\n## Objective\n\nMake Arqen applications straightforward to package, operate, and deploy.\n\n## User-visible outcome\n\nA generated app has a production Docker image, local Compose setup, readiness checks, and deployment guidance.\n\n## Dependencies\n\nPhases 02, 03, and 04. This phase is currently **blocked**.\n\n## In scope\n\nDockerfile, .dockerignore, Compose, environment examples, production logs, readiness, worker deployment, graceful shutdown, generic deployment docs, `arqen doctor`.\n\n## Out of scope\n\nCloud-specific adapter implementation, managed Kubernetes operators, billing, and application-specific infrastructure.\n\n## Required repository state\n\nA runnable app with thingd integration and workers exists.\n\n## Deliverables\n\nMulti-stage Docker build, Compose file, deployment docs, doctor diagnostics, and container smoke tests.\n\n## Acceptance criteria\n\nSee `acceptance.md`; all items must pass before completion.\n\n## Test requirements\n\nSee `test-plan.md`; record commands and outcomes in `handoff.md`.\n\n## Documentation requirements\n\nUpdate Docker and deployment docs with verified commands, ports, secrets, storage, and worker topology.\n\n## Handoff procedure\n\nComplete `handoff.md`, update `STATUS.md`, list changed files, record limitations, and identify the next phase.\n
