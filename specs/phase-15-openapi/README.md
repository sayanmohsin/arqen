# Phase 15: OpenAPI

Objective: generate OpenAPI specs from routes and request/response types.

Dependencies: 08, 09, 11.

In scope: OpenAPI generation, route discovery, schema generation, and Swagger UI.

Out of scope: external API documentation tools.

Tests: OpenAPI generation, schema generation, Swagger UI.

Docs: update OpenAPI guide.

Handoff: record OpenAPI API, schema generation, and Swagger UI.
