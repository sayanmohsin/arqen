# Scope\n\n## Intent\n\nMake application capabilities discoverable to agents and safe to run asynchronously.\n\n## Included behavior\n\nTool registration, schemas, scopes, read/write metadata, manifest generation, jobs, retry/idempotency/leases/dead letters, worker shutdown and logs.\n\n## Excluded behavior\n\nBuilt-in LLM provider, model orchestration, cloud adapter, and product-specific tools.\n\n## Change boundary\n\nWork only in the Arqen repository and the paths required by this phase. Do not modify sibling repositories unless an explicit compatibility issue is documented and approved.\n
