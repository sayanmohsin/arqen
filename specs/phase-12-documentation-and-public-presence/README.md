# Phase 12: documentation and public presence

Make Arqen understandable and verifiable as a public, language-agnostic
product while preserving its Rust-first implementation. The phase produces a
GitHub Pages VitePress site, honest repository metadata, CI quality gates, and
implementation-ready documentation conventions.

## Public identity

- Title: `Arqen`
- Tagline: `Backend infrastructure for agent-ready applications.`
- Description: `A developer-focused backend toolkit for agent-ready applications, with typed tools, durable jobs, discoverable APIs, and thingd integration.`

Dependencies: Phases 01, 02, 05, 08, 09, and 11. Scope is Arqen only; no
Watchloom, thingd, or thingd-cloud source changes are allowed.
