# Interfaces

- `arqen new NAME` creates a compiling module-based project.
- `arqen generate module/tool/job NAME` creates additive application scaffolding.
- `arqen dev` runs and clearly reports its reload behavior.
- `arqen start` runs one container-suitable server process.
- `arqen check` returns non-zero on failed checks; `doctor` gives actionable diagnostics.
- Container command: `arqen start --host 0.0.0.0 --port 8888`.
