# Scope\n\n## Intent\n\nDefine the stable Arqen contracts before framework implementation.\n\n## Included behavior\n\nRepository/crate boundaries; configuration; memory and HTTP thingd modes; startup output; health/readiness; logging/redaction; CLI behavior; tool metadata; job lifecycle; agent manifest; Docker/deployment expectations.\n\n## Excluded behavior\n\nRust implementation, CLI implementation, generated templates, cloud integration, and changes to sibling repositories.\n\n## Change boundary\n\nWork only in the Arqen repository and the paths required by this phase. Do not modify sibling repositories unless an explicit compatibility issue is documented and approved.\n
