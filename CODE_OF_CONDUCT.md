# Code of Conduct

Arqen welcomes participation from people with different backgrounds and
experience levels. Be respectful, specific, and constructive in issues,
reviews, discussions, and pull requests.

Unacceptable behavior includes harassment, discrimination, personal attacks,
unwelcome sexual attention, publishing private information, and conduct that
would make a reasonable contributor feel unsafe. Maintainers may edit, remove,
or decline contributions that violate this standard. Report concerns privately
through the security contact described in [`SECURITY.md`](SECURITY.md).
